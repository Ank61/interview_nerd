Go will not let you do this at all — an <code>if</code> statement's condition must be an actual, real boolean expression, such as <code>if age > 18</code>. You could never write <code>if age</code> by itself if <code>age</code> is a number; Go's compiler simply won't allow it. This makes Go code more predictable and removes a whole category of subtle bugs.\n</p>\n<h4 style=\"margin-top: 1.5rem; font-size: 1.25rem; font-weight: 600; letter-spacing: -0.025em\">string</h4>\n<p style=\"line-height: 1.75\">\nA <code>string</code> holds text — a sequence of characters, like a name, a sentence, or a whole paragraph. If you try to write something like <code>s[0] = 'X'</code>, Go's compiler will refuse to let you do it.
