{"title":"Error Handling","tags":[],"html":"<div>\n<p style=\"line-height: 1.75; margin-top: 1.5rem\">\nEvery real program eventually has to deal with things going wrong — a file that doesn't exist, a network request that times out, input that doesn't make sense. Go deliberately takes a very different, much simpler approach: errors are just ordinary values, returned from functions exactly like any other result, and it's entirely up to the calling code to check them and decide what to do.
