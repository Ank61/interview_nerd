The DOM still updates imperatively under the hood. Declarative approaches reduce bugs (state never desyncs from UI), enable better tooling (hot reloading, time travel), and make code more predictable and testable.<br>\n- <strong>\"Where do React hooks fit into the declarative vs imperative spectrum?\"</strong> Hooks are a hybrid — useState and useMemo are declarative (describe what state should be), useRef is imperative (direct DOM access), and useEffect is imperative (side effects, but declarative about dependencies).<br>\n- <strong>\"What's the performance trade-off of declarative vs imperative?\"</strong> Declarative (React) has faster development speed, lower bug likelihood, good performance (with React optimizations), larger bundle size, and moderate learning curve.
