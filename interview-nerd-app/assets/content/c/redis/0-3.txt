Use RPUSH to enqueue (add to tail) and LPOP to dequeue (remove from head), or vice versa. This pattern is widely used for job queues, task distribution, and message passing.\n</p>\n<p style=\"line-height: 1.75; margin-top: 0.5rem\">\n<span style=\"font-weight: 600\">Common Use Cases:</span> Background job queues, task scheduling, message brokers, work distribution, producer-consumer patterns, email queues.\n</p>\n<div style=\"padding: 2px; border-radius: 8px; font-size: 14px; margin-top: 1rem\">\n<div class=\"code\"><div class=\"code-head\"><span>bash</span><button class=\"copy\" type=\"button\">Copy</button></div><pre><code class=\"hljs\"><i class=c># Enqueue (add to tail)</i>\nRPUSH job:queue <i class=s>&quot;job1&quot;</i>\nRPUSH job:queue <i class=s>&quot;job2&quot;</i>\nRPUSH job:queue <i class=s>&quot;job3&quot;</i>\n\n<i class=c># Dequeue (remove from head)</i>\nLPOP job:queue  <i class=c># Returns &quot;job1&quot;</i>\nLPOP job:queue  <i class=c># Returns &quot;job2&quot;</i>\n\n<i class=c># Check queue size</i>\nLLEN job:queue\n\n<i class=c># Peek at next job without removing</i>\nLINDEX job:queue 0\n\n<i class=c># Atomic move between queues</i>\nRPOPLPUSH <i class=b>source</i>:queue destination:queue\n\n<i class=c># Move with rename (Redis 6.2+)</i>\nLMOVE <i class=b>source</i>:queue dest:queue RIGHT LEFT\n\n<i class=c># Priority queues using multiple lists</i>\nLPOP high:priority:queue\n<i class=c># If empty, try medium priority</i>\nLPOP medium:priority:queue\n<i class=c># If empty, try low priority</i>\nLPOP low:priority:queue</code></pre></div>\n</div>\n<h4 style=\"margin-top: 1.5rem; font-size: 1.25rem; font-weight: 600; letter-spacing: -0.025em\">\n3.
