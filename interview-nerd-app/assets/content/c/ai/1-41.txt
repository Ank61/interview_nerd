Constants, config objects, test fakes.</li>\n<li style=\"margin-top: 0.4rem\"><span style=\"font-weight: 600\">useFactory</span> &mdash; the value must be computed, especially if it needs other providers or async setup.</li>\n<li style=\"margin-top: 0.4rem\"><span style=\"font-weight: 600\">useExisting</span> &mdash; you want another name for something already registered.</li>\n</ul>\n<p style=\"line-height: 1.75; margin-top: 1.0rem\">\nA quick test: if you find yourself writing <code>new Something()</code> inside <code>useValue</code> and it needs config, you wanted a factory.\n</p>\n<h4 style=\"margin-top: 1.5rem; font-size: 1.25rem; font-weight: 600; letter-spacing: -0.025em\">\nA Factory Can Return Anything\n</h4>\n<p style=\"line-height: 1.75; margin-top: 1.0rem\">\nIt does not have to return a class instance.
