For each one: read the PDF,\n  pull out the fields, check the numbers add up, match it to\n  a purchase order, route it for approval, post it to the\n  ledger.\n\nWHAT WAS PROPOSED\n  An agent with tools: read_invoice, lookup_po, check_totals,\n  route_approval, post_to_ledger. The real question is whether the <em>identity</em> of the next step depends on what the last one found.\n</p>\n<h4 style=\"margin-top: 1.5rem; font-size: 1.25rem; font-weight: 600; letter-spacing: -0.025em\">\nOther Clear No's\n</h4>\n<ul style=\"margin-top: 1.0rem; margin-left: 1.5rem; list-style-type: disc\">\n<li style=\"margin-top: 0.5rem\"><strong>High volume, low value each.</strong> Agent economics fall apart. A few pence per request is fine for a thousand requests and not fine for a million.</li>\n<li style=\"margin-top: 0.5rem\"><strong>Someone is waiting.</strong> If a person is watching a cursor blink, a variable four-to-twenty-second response is a bad product regardless of how good the answer is.</li>\n<li style=\"margin-top: 0.5rem\"><strong>Regulated or audited work.</strong> \"The system followed these defined steps\" is a much easier conversation than \"the model chose its own approach\".</li>\n<li style=\"margin-top: 0.5rem\"><strong>There is nothing to choose between.</strong> An agent with two tools is not an agent. It is a branch with extra latency.</li>\n<li style=\"margin-top: 0.5rem\"><strong>You cannot evaluate it.</strong> If you have no way to tell good from bad at scale, you cannot ship an agent responsibly, because you will not notice it getting worse.</li>\n<li style=\"margin-top: 0.5rem\"><strong>Every step has serious side effects.</strong> If a wrong move costs real money and cannot be undone, you want a fixed path with gates, not a model choosing.</li>\n</ul>\n<h4 style=\"margin-top: 1.5rem; font-size: 1.25rem; font-weight: 600; letter-spacing: -0.025em\">\nThree Reasons That Sound Good But Are Not\n</h4>\n<div style=\"padding: 2px; border-radius: 8px; font-size: 14px\">\n<div class=\"code\"><div class=\"code-head\"><span>code</span><button class=\"copy\" type=\"button\">Copy</button></div><pre><code class=\"hljs\">&quot;WE NEED AN AGENT - IT KEEPS PICKING THE WRONG TOOL.&quot;\n  That is a tool description problem.
