If it goes into a web page you get cross-site scripting; into a database query you get SQL injection; into a shell you get command execution. And a rendered markdown image is a real data-exfiltration route: the model writes an image link pointing at an attacker's server with secret data in the URL, and the user's browser fetches it. Nobody clicks anything.\n</p>\n<p style=\"line-height: 1.75; margin-top: 1.0rem\">\n<strong>System prompt leakage.</strong> The right response is not to try harder to hide it. <em>Assume it will leak</em> and make that fine — no keys, no credentials, no rules that only work because they are secret. If your prompt leaking is a security problem, you were treating it as a boundary, and it never was one.\n</p>\n<h4 style=\"margin-top: 1.5rem; font-size: 1.25rem; font-weight: 600; letter-spacing: -0.025em\">\nOrdinary Security Still Applies\n</h4>\n<p style=\"line-height: 1.75; margin-top: 1.0rem\">\nThis list is <strong>additional</strong>, not a replacement.
