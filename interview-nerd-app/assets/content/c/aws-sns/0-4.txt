Reach for <strong>MessageBody</strong> when the event shape is fixed by someone else.</p>\n<h4 style=\"margin-top: 1.5rem; font-size: 1.25rem; font-weight: 600\">The Operators, With Examples</h4>\n<p style=\"line-height: 1.75\">A policy is a JSON object: each key is an attribute (or body field) name and each value is an <strong>array</strong> of conditions. Here is the full working set.</p>\n<ul style=\"margin-left: 1.5rem; list-style: disc; line-height: 2\">\n<li><strong>Exact string match.</strong> <code>{\"eventType\": [\"order_placed\"]}</code> — matches only that exact string.</li>\n<li><strong>List of allowed values (OR).</strong> <code>{\"eventType\": [\"order_placed\", \"order_cancelled\"]}</code> — matches if the value is any one of them.</li>\n<li><strong>anything-but.</strong> <code>{\"eventType\": [{\"anything-but\": [\"order_test\"]}]}</code> — matches everything except the listed values. Works with strings, lists and numbers.</li>\n<li><strong>Numeric matching.</strong> <code>{\"orderTotal\": [{\"numeric\": [\"=\", 100]}]}</code> for equality, and for a range <code>{\"orderTotal\": [{\"numeric\": [\">=\", 10000, \"&lt;\", 50000]}]}</code> — greater-or-equal 10000 and less than 50000. Operators are <code>=</code>, <code>&lt;</code>, <code>&lt;=</code>, <code>&gt;</code>, <code>&gt;=</code>. The attribute must be published with DataType <strong>Number</strong>, or (for body scope) be a JSON number.</li>\n<li><strong>prefix.</strong> <code>{\"eventType\": [{\"prefix\": \"order_\"}]}</code> — matches any value starting with that text.</li>\n<li><strong>suffix.</strong> <code>{\"filename\": [{\"suffix\": \".csv\"}]}</code> — matches any value ending with that text.</li>\n<li><strong>exists.</strong> <code>{\"couponCode\": [{\"exists\": true}]}</code> matches messages that have the attribute at all, whatever its value; <code>{\"exists\": false}</code> matches messages that lack it entirely.</li>\n<li><strong>IP address matching.</strong> <code>{\"sourceIp\": [{\"cidr\": \"10.0.0.0/24\"}]}</code> — matches an address inside that CIDR block.</li>\n<li><strong>Combining with anything-but plus prefix.</strong> <code>{\"eventType\": [{\"anything-but\": {\"prefix\": \"internal_\"}}]}</code> — everything whose value does not start with that text.</li>\n</ul>\n<p style=\"line-height: 1.75\">Now the two combination rules, which are the heart of the whole feature and a guaranteed interview question:</p>\n<div class=\"code\"><div class=\"code-head\"><span>python</span><button class=\"copy\" type=\"button\">Copy</button></div><pre><code class=\"hljs\">{\n  <i class=s>&quot;eventType&quot;</i>:    [<i class=s>&quot;order_placed&quot;</i>, <i class=s>&quot;order_cancelled&quot;</i>],   &lt;-- OR  within one key\n  <i class=s>&quot;customerTier&quot;</i>: [<i class=s>&quot;gold&quot;</i>]                               &lt;-- AND across keys\n}\n\nMatches when:  (eventType = order_placed OR order_cancelled)\n               AND\n               (customerTier = gold)\n\nA message missing EITHER attribute does <i class=k>not</i> <i class=k>match</i> at <i class=b>all</i>.</code></pre></div>\n<p style=\"line-height: 1.75\">Several values for one attribute are <strong>OR</strong>.
