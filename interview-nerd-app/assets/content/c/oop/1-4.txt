its state cannot be changed. Instead of modifying existing objects, new objects are created with the desired changes. This principle is fundamental in functional programming and provides several benefits.\n</p>\n<h4 style=\"margin-top: 1.5rem; font-size: 1.25rem; font-weight: 600; letter-spacing: Behavior:</span> No unexpected side effects from object modification\n</li>\n<li style=\"margin-top: 0.5rem\">\n<span style=\"font-weight: 600; font-size: 1.1rem\">Easier Debugging:</span> State
