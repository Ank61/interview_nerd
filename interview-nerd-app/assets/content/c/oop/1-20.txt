It encapsulates object creation logic and allows the client to request objects using a common interface. This pattern is useful when the creation process is complex or when you need to create different types of objects based on certain conditions.\n</p>\n<h4 style=\"margin-top: 1.5rem; font-size: style=\"font-weight: 600; font-size: 1.1rem\">Flexibility:</span> Easy to add new product types without changing existing code.\n</li>\n<li style=\"margin-top: 0.5rem\">\n<span style=\"font-weight: 600; font-size: 1.1rem\">Abstraction:</span> Clients don't need to know concrete classes.\n</li>\n<li style=\"margin-top: 0.5rem\">\n<span style=\"font-weight: 600; font-size: 1.1rem\">Loose
