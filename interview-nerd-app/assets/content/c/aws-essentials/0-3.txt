Deployed per AZ for resilience.</li>\n<li><strong>Security Groups:</strong> Stateful, instance-level, allow rules only. Can reference other security groups.</li>\n<li><strong>Network ACLs:</strong> Stateless, subnet-level, ordered allow and deny rules.
