font-size: 1.25rem; font-weight: 600; letter-spacing: -0.025em\">\nWhere Metadata Actually Lives\n</h4>\n<p style=\"line-height: 1.75; margin-top: 1.0rem\">\nUnderneath, <code>SetMetadata</code> uses the <code>reflect-metadata</code> library, which stores values in a <code>WeakMap</code> keyed on the class or method. <code>Reflector</code> is a thin wrapper over reading it back.\n</p>\n<p style=\"line-height: 1.75; margin-top: 1.0rem\">\nTwo consequences. Metadata is written <span style=\"font-weight: 600\">once, when the class is defined</span> &mdash; not per request &mdash; so reading it is cheap.
